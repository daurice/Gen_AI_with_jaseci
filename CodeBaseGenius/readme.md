# Codebase Genius

Autonomous documentation generator for Python and Jac codebases.

## Features
- Clones public GitHub repos
- Builds file tree & summarizes README
- Parses code with Tree-sitter
- Constructs Code Context Graph (CCG)
- Generates rich Markdown docs with diagrams
- HTTP API + downloadable output

## Setup

```bash
pip install -r requirements.txt
